Mango Leaf Disease Detection

This paper presents a deep learning-based system for detecting and classifying mango leaf diseases using 12,729 images across eight classes. It compares multiple transfer learning models and integrates Grad-CAM explainable AI with ResNet50, achieving 99.36% accuracy while highlighting disease-relevant leaf regions to improve interpretability and support practical field deployment.
